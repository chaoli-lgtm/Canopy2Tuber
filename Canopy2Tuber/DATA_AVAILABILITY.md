# Data availability

The source code, supplied model weights, fitted parameter files, documentation and synthetic examples in this package are distributed under the MIT License; see `LICENSE` and the licensing scope in `README.md`.

The complete raw phenotypic data are available from the corresponding author upon reasonable request and are not covered by the software license. Full data supplied for peer review are not included in this public package.

All CSV files under `example_data/` are synthetic examples, not field observations or validation data. Their outputs demonstrate execution only. Fitted parameter banks contain model coefficients, not raw phenotypic records.
